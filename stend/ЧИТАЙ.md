# Стенд: приложение на ПК и снимки для документации

Здесь то, чем сняты картинки в `docs/images/screens/`. Ничего из этого не
нужно, чтобы пользоваться приложением, — только чтобы повторить снимки или
посмотреть изменение, не трогая телефон.

## Как это устроено

Настольная сборка — тот же код под Qt 4.7.3 из QtSDK, то есть ровно тот Qt,
под который собирается телефон. QtSDK показывает её не своим окном, а внутри
**Qt Simulator**; если в его панели *View* выбрать устройство
**Symbian NonTouch** и выставить *Zoom* вправо, экран становится настоящим
240×320 в скине Nokia N95 — внешний экран E90.

Библиотеку выдаёт сервер-макет: выдуманные записи из общественного достояния,
чтобы на картинках не было ни чужих файлов, ни адресов.

## Запуск

```
REM 1. сервер-макет: по-русски и по-английски
python maket-jellyfin.py 8099
python maket-jellyfin.py 8098 en

REM 2. сборка (из каталога klient)
robocopy . C:\jkwin\klient-en /MIR /XD .git debug release
cd C:\jkwin\klient-en
set PATH=C:\QtSDK\Simulator\Qt\mingw\bin;C:\QtSDK\mingw\bin;%PATH%
qmake -spec win32-g++ DEFINES+=JF_EN
mingw32-make release

REM 3. настройки приложения на ПК лежат в %TEMP%\settings.ini
REM    (server=http://127.0.0.1:8098, token=demo -- тогда вход не спрашивается)
```

## Скрипты

| Файл | Что делает |
|---|---|
| `ШАГ.ps1` | нажать клавиши в симуляторе и снять экран (`-Skin` — со скином) |
| `СНЯТЬ.ps1` | снять чужое окно через `PrintWindow`, даже закрытое другими |
| `ЩЕЛЧОК.ps1` | щёлкнуть по чужому окну, честно подняв его на передний план |
| `ОБРЕЗАТЬ.ps1` | вырезать прямоугольник из снимка |

Пример прохода по экранам:

```
.\ШАГ.ps1 -Fayl 01-library.png
.\ШАГ.ps1 -Knopki '{ENTER}' -Fayl 02-settings.png -Pauza 1400
.\ШАГ.ps1 -Knopki '{BS}','{DOWN}','{DOWN}','{DOWN}','{ENTER}' -Fayl 03-series.png
```

## Чего ждать

* Экран телефона лежит в снимке окна симулятора (768×768) по постоянным
  координатам: само приложение — `263, 154, 240×256`, весь телефон со
  скином — `230, 10, 310×740`.
* Windows не отдаёт фокус фоновому процессу: без приёма с `AttachThreadInput`
  щелчки и клавиши уходят в чужое окно. Это уже учтено в скриптах.
* Шрифт стенда склеивает «кэ» в «ю» — «Очистить кэш музыки» выходит
  «Очистить юш музыки». Это шрифт настольного Qt, а не приложение: тот же
  дефект виден на тексте, пришедшем с сервера.

Стенд не заменяет телефон: звука, софт-клавиш, клавиатуры и настоящей
скорости здесь нет, а именно там живут сюрпризы.
